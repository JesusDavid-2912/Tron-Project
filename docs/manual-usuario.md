# Manual de usuario

## Antes de jugar

- Se necesitan al menos 2 jugadores. La sala admite hasta 6.
- Una persona debe iniciar el servidor y mantenerlo abierto durante la partida.
- Los jugadores pueden usar Windows o Linux. Si se conectan desde equipos distintos, deben estar en una red que permita comunicarse con el equipo anfitrión.
- Pide a quien organiza la partida la dirección del servidor si juegas desde otro equipo.

## Abrir el juego

### Windows

1. En el equipo anfitrión, abre `TronServidor.exe`. Mantén abierta la ventana que aparece mientras juegan.
2. En cada equipo jugador, abre `TronCliente.exe`.

### Linux

1. En el equipo anfitrión, abre **Tron Lightcycle Server** desde el menú de aplicaciones. Mantén abierta la terminal que aparece mientras juegan.
2. En cada equipo jugador, abre **Tron Lightcycle Arena** desde el menú de aplicaciones.

El anfitrión también puede jugar: inicia el servidor y después abre un cliente en ese equipo. Para cerrar el servidor al terminar, cierra su ventana; en Linux también puedes pulsar `Ctrl+C` en la terminal del servidor.

## Conectarse a una partida

1. En **Servidor / IP**, escribe la dirección que te dio el anfitrión. Si el cliente y el servidor están en el mismo equipo, usa `127.0.0.1`.
2. Deja el puerto `5050`, salvo que el anfitrión indique otro.
3. Escribe el nombre con el que aparecerás en la partida.
4. Pulsa **CONECTAR** y espera a que aparezcas en la lista de pilotos.
5. Cuando haya al menos dos jugadores conectados, cualquiera puede pulsar **INICIAR CARRERA**.

## Controles

- Usa las flechas o `W`, `A`, `S`, `D` para cambiar la dirección.
- No es posible girar directamente en sentido contrario.
- Evita los bordes del tablero y las estelas luminosas, incluida la tuya.
- Gana el último piloto que permanezca en pista.
- Al terminar la ronda, pulsa **JUGAR OTRA VEZ** para comenzar una nueva.

## Si no puedes conectarte

- Confirma que el servidor está abierto y que el anfitrión todavía no lo cerró.
- Revisa la dirección del servidor y el puerto indicado.
- Si juegas desde otro equipo, pide al anfitrión que compruebe que la red y el firewall permiten la conexión.
- Si todavía no aparece **INICIAR CARRERA**, espera a que se conecte el segundo jugador.
